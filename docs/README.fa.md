# مستندات نکسورا

[English](README.md) | [فارسی](README.fa.md)

این پوشه مرجع مهندسی نگهداری‌شدهٔ فرانت‌اند نکسورا است. هر سند هدف مشخصی دارد تا جزئیات پیاده‌سازی، وضعیت محصول و نیازهای محیط واقعی با یکدیگر مخلوط نشوند.

بک‌اند چرخهٔ عمر و مخزن مستقل خود را دارد: [`HmdAK19/nexora-api`](https://github.com/HmdAK19/nexora-api). این مستندات فقط قرارداد مورد انتظار و مسئولیت‌های فرانت‌اند را تعریف می‌کنند.

## قواعد منبع حقیقت

- هنگام اختلاف کد و مستندات، پیاده‌سازی مرجع است و سند باید در همان تغییر اصلاح شود.
- «یکپارچه‌شده در فرانت‌اند» فقط به معنی پیاده‌سازی UI و مصرف قرارداد است و وجود سرویس واقعی تولید را اثبات نمی‌کند.
- کنترل‌هایی که به سرور وابسته‌اند به‌عنوان الزام بک‌اند توصیف می‌شوند، نه تضمین UI.
- payloadهای نمونه نباید شامل credential، اطلاعات شخصی یا secret واقعی باشند.
- تصویرها از دادهٔ مصنوعی قطعی استفاده می‌کنند و اطلاعات مشتری ندارند.

## نگهداری ترجمه‌ها

انگلیسی سند مرجع است و فایل فارسی هم‌نام با پسوند `.fa.md` کنار آن قرار می‌گیرد. هر دو نسخه باید در یک تغییر به‌روزرسانی شوند. `npm run docs:check` وجود جفت‌ها، لینک تغییر زبان و revision متن مرجع را بررسی می‌کند تا ترجمهٔ قدیمی وارد شاخهٔ اصلی نشود.

هر تغییر در route، مجوز، رفتار، API، WebSocket، معماری، اعتبارسنجی، امنیت، responsive، accessibility، آزمون، build یا عملیات باید سند مرتبط را در هر دو زبان به‌روزرسانی کند.
